# Приёмка Stasy Bell OS V2 — границы завершения

## Проверено в CI на синтетических данных
- Миграции PostgreSQL 0001–0006, защита от пересечения записей и блоков, календарь/рабочие окна, конкурентное бронирование, истечение hold.
- Авторизация мастера, собственная цена/длительность услуги и неизменяемый снимок стоимости в исторической записи.
- Telegram/VK webhook verification, 45 минут hold, 15 минут token, переиздание, replay/idempotence, очередь уведомления мастеру с повторами.
- Ручная запись без телефона, календарные изменения и журнал, фактические доходы и расходы, закрытие месяца, журнал склада.
- Offline dry-run XLSX на полностью синтетических книгах, включая ошибки и дубликаты.
- Полный сценарий сайт → Telegram callback → подтверждённая запись → завершение услуги → доход → расход материала.
- GitHub Actions: FastAPI/PostgreSQL tests, восстановление PostgreSQL с тестовой строкой, React TypeScript/прайс/production build, Android assembleDebug/unit tests. APK debug доступен через GitHub Actions Artifact на 3 суток.

## Не проверено / требует внешнего ввода
- Реальные Telegram/VK credentials, webhook URL с TLS, сообщения настоящему клиенту и владельцу.
- Эмулятор пользователя: установка APK и прохождение по экранам; в CI проверены только debug build и JVM tests, не UI instrumentation.
- Реальные Excel клиентов/финансов: ещё не получены. Перенос в staging/production без подтверждённых исходников запрещён.
- Боевой сервер в России, домен, HTTPS, секреты, мониторинг, резервное копирование с вынесением за хост.
- Юридически согласованные тексты обработки персональных данных, политика хранения и удаления; реальный пользовательский приёмочный чек-лист Насти.
- Production-нагрузка, Push вне Telegram, корректность всех вариантов прайса — требуют отдельного продуктового утверждения.

## Условия запуска
1. Предоставлены исходные таблицы приватным способом и согласован нормализованный маппинг, суммы и количество строк.
2. Пройдена приёмка на эмуляторе с изолированной БД и фейковыми клиентами.
3. Настроены российский хост, TLS, отдельные секреты, CORS, webhook и оповещения.
4. Проверен реальный контрольный цикл Telegram/VK и уведомление владельцу.
5. Финальная сверка прайса/длительностей, бюджета, безопасности и бэкапов. До этого PR остаётся Draft, `main` и Pages неизменны.

Нет оснований объявлять продукт боевым или сливать ветку только из-за зелёного CI.
