# Stasy Bell V2 — персональные данные: блокер запуска

Обновлено: 05-11-2026. Черновик, не юридическое заключение.

## Уже сделано
- Самостоятельный экран /#privacy, ссылка в подвале и рядом с отдельным согласием.
- Форма онлайн-записи по умолчанию выключена, даже если указан HTTPS API.
- Для открытия требуются VITE_PRIVACY_APPROVED=1 и четыре поля:
  VITE_PRIVACY_OPERATOR, VITE_PRIVACY_OPERATOR_ADDRESS, VITE_PRIVACY_CONTACT,
  VITE_PRIVACY_RETENTION. Они будут видны посетителям в готовом сайте.
- В CI для синтетических сценариев используются только вымышленные реквизиты.
- Нет рекламной рассылки, онлайн-платежей и персональных данных в Git.

## Что подтвердить до запуска
- [ ] Действительные сведения оператора (ИП/самозанятый/организация), адрес для обращений.
- [ ] Контакт для запроса доступа, исправления, отзыва согласия и удаления.
- [ ] Сроки хранения/удаления клиентов, записей, мессенджер-ID, журналов и исключения.
- [ ] Юридическая редакция политики и отдельного согласия.
- [ ] Обязанности уведомления Роскомнадзора, договоры с обработчиками.
- [ ] Сервер и первоначальный сбор/хранение в РФ, доступ, резервирование, журналирование.
- [ ] Фактические правила Telegram/VK и потенциальная трансграничная передача.
- [ ] Проверка текста /#privacy и успешный staging-прогон после внесения настоящих реквизитов.
- [ ] Отдельное разрешение владельца на включение публичной формы и снятие noindex.

## Критерий
Без утверждения формы нет. С согласием — только временная бронь.
Подтверждённой запись становится исключительно после проверенного callback Telegram/VK.
