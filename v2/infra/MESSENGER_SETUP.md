# Подключение мессенджеров после получения токенов

Секреты остаются в частном `v2/.env` с правами 600. Проверка `python v2/infra/messenger_setup.py check --env v2/.env --base-url https://ВАШ-API-ДОМЕН` **ничего не изменяет**.

Когда подготовлены реальный HTTPS домен и Telegram-бот, команда
`python v2/infra/messenger_setup.py register-telegram --env v2/.env --base-url https://ВАШ-API-ДОМЕН --apply`
регистрирует Telegram webhook автоматически, передавая секретный заголовок и только события `message`, `callback_query`. Выполнение без `--apply` заблокировано, URL токена никогда не печатается.

VK требует настроенного сообщества: Callback API → добавить сервер `https://ВАШ-API-ДОМЕН/callbacks/vk`, скопировать код подтверждения `VK_CONFIRMATION_CODE`, настроить `VK_CALLBACK_SECRET` и событие `message_new`. Проверка значений включена; произвольное добавление сервера VK без отдельной проверки прав и существующих настроек не автоматизировано.

Даже после вставки ключей публичная запись **не включается автоматически**: требуется проверка реальной доставки и решение о запуске. `main`, старый сайт и клиентские данные не затрагиваются.
